# Microbiome Workflows (Generic Template)

This folder outlines a structure for microbiome analysis projects (16S and ITS) associated with grapevine or related environments.

Recommended structure:

- `data/` – links or descriptions of stored sequence data
- `scripts/` – pipeline scripts for 16S/ITS processing
- `notebooks/` – exploratory analyses and visualization
- `results/` – diversity metrics, ordinations, taxonomic summaries
- `docs/` – methodological notes, decisions, and interpretation

No raw sequencing data or confidential information should be stored here.
