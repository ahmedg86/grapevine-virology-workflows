# Project Template

This folder shows how I organize research projects in this repository. It is only a structure, not a real project.

## Folders

- **data/** – (empty) information about where data comes from
- **scripts/** – code used in the analysis
- **notebooks/** – Jupyter or R notebooks
- **results/** – figures or summary tables
- **docs/** – notes about methods or interpretation

This is only a template to keep future projects organized.
No data or unpublished results are included.
