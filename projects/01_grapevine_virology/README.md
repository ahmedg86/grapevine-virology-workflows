# Grapevine Virology Project (Generic Template)

This folder provides a generic structure for organizing a grapevine virology project. It is not tied to a specific dataset or publication.

Suggested subfolders (create as needed):

- `data/` – metadata, references to where raw data are stored (not in this repo)
- `scripts/` – analysis scripts and workflows
- `notebooks/` – R or Jupyter notebooks for exploratory analysis
- `results/` – summary tables, plots, and derived metrics
- `docs/` – project notes, methods, and interpretation outlines

Use this as a starting point for future grapevine virology analyses.
