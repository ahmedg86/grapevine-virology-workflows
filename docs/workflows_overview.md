# Workflows Overview

This document summarizes the main workflow templates available in this repository.

- **HTS data processing:** `protocols/bioinformatics/HTS_processing_template.md`
- **Virus discovery:** `protocols/bioinformatics/virus_discovery_template.md`
- **16S microbiome workflow:** `protocols/bioinformatics/microbiome_16S_template.md`
- **ITS microbiome workflow:** `protocols/bioinformatics/microbiome_ITS_template.md`
- **Lab diagnostics template:** `protocols/lab/virus_diagnostics_template.md`

Each template is designed to be generic and adaptable, without embedding project-specific or unpublished details.
