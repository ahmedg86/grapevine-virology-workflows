# Repository Structure

This repository is organized to separate workflows, environments, and project templates.

- `envs/` – Conda environment definitions
- `protocols/` – General lab and bioinformatics workflow descriptions
- `projects/` – Project-level templates and organizational scaffolds
- `scripts/` – Shared example scripts for common tasks
- `docs/` – Documentation about repository usage and structure

Raw data should not be stored here. Instead, this repository focuses on reproducibility, documentation, and workflows.
